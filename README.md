# FolioTone

An Android EPUB reader with private book storage, saved reading position, text-to-speech narration, and an Android Auto media library. FolioTone is a provisional working name; verify availability before publishing.

For implementation context, recent fixes, verification history, and remaining work, see the [development handoff](docs/DEVELOPMENT_HANDOFF.md).

For the source-only archive and instructions to recreate excluded dependencies and model downloads, see [archive restoration](ARCHIVE_RESTORE.md).

## Build

For natural narration without per-character fees, deploy your own Voxtral narration server on Modal: see [tts-server/README.md](tts-server/README.md).

For a local Qwen3-TTS speech playground on Apple Silicon, see [Voice Lab](tts-lab/README.md). It provides a browser UI and local server for testing narration independently of the Android app.

Open the directory in Android Studio, install Android SDK 35, and run the `app` configuration. From a terminal with the Android SDK and Java 17 available, run `./gradlew assembleDebug`. The first build downloads Gradle and Maven dependencies.

## Releases

Every push to `main`, including merged pull requests, runs [the release workflow](.github/workflows/release.yml). It builds a signed release APK and publishes it as a GitHub release named `v<VERSION>.<run number>`, for example `v1.0.7`. Edit [VERSION](VERSION) to change the first part, such as `1.1`. The run number also becomes the Android `versionCode`, so every release can be installed over the previous one. To check a branch before merging, open **Actions → Release → Run workflow** and pick the branch. That run only builds the APK and attaches it to the run without publishing a release.

Signing uses FolioTone's own release key, which doesn't depend on Android Studio. Create it once on the Mac:

```sh
tools/create-release-key.sh
```

This creates `~/Projects/Signings/foliotone-signing/` with the key (`foliotone-release.jks`), a base64 copy, `keystore.properties` and `README-signing.txt` (passwords, certificate SHA-256 and restore steps). Keep that folder private and backed up: losing it means releases can no longer update the app. The script also copies `keystore.properties` into the project (ignored by git), so Android Studio's debug and release builds use the same key and install over GitHub releases. If the GitHub CLI is signed in, it replaces the four repository secrets the workflow reads (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`). Otherwise, add them under **Settings → Secrets and variables → Actions** from the values in `README-signing.txt`.

Switching an installed app to a new key takes one reinstall. Back up its data first with [tools/reinstall-keep-data.sh](tools/reinstall-keep-data.sh), which needs the installed build to be a debug build. After that, enter the ElevenLabs key and the narration server connection again, because they're encrypted with a device key that Android removes on uninstall.

### Updates inside the app

FolioTone checks GitHub's latest release when it opens (at most every 6 hours) and twice a day in the background. When a newer release exists, it downloads the APK, checks it against the release's `SHA256SUMS.txt` and against the installed app's signing key, and offers **Install now / Later**. The background check shows a notification instead. **Listening settings → App updates** shows the installed version, checks on demand, installs a downloaded update and turns automatic downloads off. Installing always starts with your tap. The first time, Android asks you to allow FolioTone to install apps and to confirm the install. On Android 12 and later, once FolioTone has installed itself, later updates install without the system confirmation. Builds from Android Studio (debuggable) never check automatically, so a development build is not replaced by a release, but you can still check by hand. The update can only install when the release and the installed app are signed with the same key.

### In the car (Android Auto)

FolioTone shows three tabs in Android Auto. **Continue** lists recently read books with their cover, place and progress, and tapping one resumes it. **Library** is a cover grid, and each book opens its chapters with the current one marked. **Chapters** lists the chapters of the current book. Saying "play <title> on FolioTone" finds a book by voice. The playback screen has Section start, plus Replay for non-Google device voices.

Android Auto only shows apps installed from the Play Store unless you allow others. On the phone, open **Android Auto settings**, tap **Version** about 10 times to unlock developer settings, then use the ⋮ menu → **Developer settings** → **Unknown sources**. Without this, tapping FolioTone in the car asks you to use the phone.

## Use

- **Import EPUB** copies a selected book into private app storage and extracts its cover. **Choose folder** grants access to a user-selected folder, scans its EPUB files, and copies them into the same library. Use **Scan folder again** after adding files. Books without an embedded cover receive a styled placeholder.
- **Browse Project Gutenberg** on the home screen shows popular books and searches titles or authors. [Gutendex](https://gutendex.com/) supplies paged catalog metadata; the app selects EPUB books in English, Italian, French, German, and Spanish from each page. The catalog match count includes all languages and formats. The user navigates one page at a time and selects individual EPUBs to download from Project Gutenberg. Downloads continue through a foreground service if the screen is recreated, show progress in a notification, and can be cancelled. They use the same 100 MB validation and private library storage as local imports. Saved Gutenberg IDs identify books already in the library. Availability and copyright status can differ outside the United States; check [Project Gutenberg's terms](https://www.gutenberg.org/policy/terms_of_use.html) and local rules before downloading. Catalog search sends the query to Gutendex, a third-party service.
- The home screen shows the last opened book first, followed by a vertical library with real EPUB covers or simple typographic placeholders. Tap a book to read. Drag the section progress bar to move within the current section. The reader keeps previous, listen/pause, and next controls visible. Tap Contents for a searchable list of numbered sections, page counts, and direct navigation; voice options open from their own button.
- Progress is saved after each page change. The **Resume one page earlier** setting applies when reopening a book from the library.
- Use **List** or **Grid** beside the library filter to switch between compact rows and a cover grid. Your choice is saved across app restarts. Both layouts support read/unread filtering, progress, ratings, tap-to-read, and long-press book actions. The grid adapts its column count to the screen width.
- The Android media widget shows the book cover (or a generated title cover), book title, section number/title, and page position. Its seek bar uses a millisecond timeline for the current section; section duration is estimated from text length and narration speed because audio is generated per page. Within-page progress uses speech range callbacks or actual cloud playback position, with elapsed-time estimates for device voices without range callbacks. Scrubbing resumes at the beginning of the selected page. Android controls the artwork's exact presentation on the lock screen and notification panel. Tapping the media notification opens the current book without rewinding or interrupting playback.
- **Mark as read** in the reader lets you mark any book read or unread without moving its saved position. Long-press a library book for the same action. The library offers **All books**, **Unread**, and **Read** filters. By default, finishing the final narrated page or pressing Next beyond the final page marks the book read. Turn off **Automatically mark finished books as read** in Listening settings to use manual status only. Reopening a read book keeps its status; marking it unread lets you track another read.
- **Themes** on Home, in the reader, or in Listening settings opens 20 named palettes with color previews: Folio, Polar, Candy, Paper, Midnight, Ocean, Forest, Lavender, Rose, Sunset, Ember, Sand, Mint, Sky, Plum, Cocoa, Slate, Monochrome, Cherry, and Lemon. The choice applies immediately to the interface and reading page, adjusts system-bar icon colors, and survives app restarts.
- **Rate this book** in the reader saves a personal score from **0.0 to 5.0 stars**, in steps of **0.1**. Use the slider and fine-adjustment buttons, then save; ratings can be edited or removed. **Ratings & best books** on the home screen shows your highest and lowest rated books, all books alphabetically, or books you have not rated, plus your average score. Ratings stay on the device, survive app restarts, and appear beside rated books in the library. An unrated book is distinct from a **0.0** rating.
- EPUB language metadata is used when it names English, Italian, French, German, or Spanish. Otherwise a small sample is checked and the reader asks for a language if it is unclear. **Voice & options** lets you change the book language.
- **Play**, **Pause**, **Stop**, **Start section**, previous/next page, and previous/next section control spoken reading. Open **Listening settings** from the library or reader to select **Device voices** or **ElevenLabs**. Device voices use Android's installed speech providers, work offline when the selected voice is installed locally, and are saved per provider and language. Google and Samsung downloads appear under their respective providers. Online device voices require a connection; if one fails during playback, the app tries an offline voice.
- **Your narration server** is a third narration source: the user's own Voxtral 4B TTS server on Modal ([tts-server](tts-server/README.md)). Connect it in Listening settings with the server address and a Modal proxy auth token (stored encrypted, outside Android backup), then choose and preview a voice per language; each language defaults to its native voice. Open a book and choose **Manage offline audio → Download book audio**: the app sends the page text to the server, which generates the whole book on a GPU while the app downloads each finished page into private storage. Playback uses only saved pages, so it works offline; a page without saved audio pauses with a hint to download. Audio is generated at normal speed and the narration speed is applied during playback, so changing speed needs no new audio, while changing the voice does. Pausing a download leaves the server job running; resuming continues it.
- **Manage offline audio** offers parts of the book for both cloud sources: **from your current page to the end**, the **rest of this section**, or the **whole book**, each with the number of pages still missing for the current voice and an estimate (server minutes and storage, or ElevenLabs credits). This lets a reader who is partway through switch voice or source and generate only what is left. Pages before the chosen start keep whatever audio they had; playback pauses on a page without audio for the current voice, unless the auto-switch below is on.
- The library and the Continue card show a 🎧 badge when narration is saved on the device: **downloaded** (every page, in bold), a **percentage** for part of the book, or **saved for another voice** when the audio belongs to a voice that is no longer selected. **Listening settings → Downloaded narration** shows the space used and can **delete all downloaded narration** (server and ElevenLabs audio) at once; books, progress, voices and keys stay.
- The app is available in **English and Spanish**: **Listening settings → App language** (System default, English, Español). Book text and narration voices are not affected.
- **Regenerate this page** (Voice & options, for the server and ElevenLabs) creates the current page's audio again when it sounds wrong or will not play. The server runs a separate one-page job that does not disturb a paused book download; ElevenLabs uses about one credit per character of the page.
- **Use the device voice for pages without saved audio** (server settings, off by default) lets you listen straight through a partly downloaded book: pages without saved server audio, or whose saved file cannot be played, are read by the device voice, and the server voice returns on the next saved page. Removing the server deletes its settings and all saved server audio.
- **ElevenLabs** uses a user supplied API key and the `eleven_multilingual_v2` model. Connect the key in Listening settings, then choose and preview a voice for each book language. Narration uses the same phone and Android Auto controls. Each page of book text is sent to ElevenLabs when audio is generated, which uses the user's account credits and requires internet; recent generated MP3 pages are cached privately on the device for replay. Voice previews also use credits. Removing the key also removes cached audio. The key is encrypted with Android Keystore and stored outside Android backup. For a shared or published app, use a backend or short lived tokens instead of distributing an API key in the app.
- To listen to an ElevenLabs book offline, open it and choose **Manage offline audio → Download book audio** while connected. The app generates and saves every page for the selected voice and narration speed in private storage. It shows progress in the reader and a notification while working in the background. You can pause and later download the remaining pages, or remove a book's offline copies. Generating pages uses ElevenLabs credits and may take considerable time and storage for a long book. Changing the voice or speed requires new audio; the offline copies for earlier choices remain until removed. Replacing or removing the API key clears all saved ElevenLabs audio. Android's online device voice models belong to the selected speech provider and cannot be downloaded by FolioTone; use **Download more voices** in Listening settings to install an offline voice through that provider.
- During ElevenLabs playback, the app generates one page ahead and reuses that result at the next page turn, including when the turn crosses a section boundary. This lookahead can use credits for a page the listener has not reached yet. A pause, seek, voice change, or source change cancels pending lookahead. Android device voices keep the next page in the TTS queue and extend that queue as reading advances, so normal page turns no longer flush and restart the provider. Online TTS providers control when queued speech is synthesized, so a slow network may still cause a pause.
- To connect ElevenLabs, create a key under **Developers → API Keys** and copy its full value at creation time. Give it **Voices (read)** and **Text to Speech** access. ElevenLabs only shows the key name and last four characters afterward; those cannot be used to connect. A 401 means ElevenLabs rejected the key or it expired, while a 403 usually points to permissions or an IP restriction. The app accepts a bare key or a copied `xi-api-key:` header and lets you show the pasted value to check it before submitting.
- Android Auto shows the book library and section list through a media browser service. Car playback controls and supported Assistant play, pause, next, and previous voice actions reach the same reading position.
- Narration and voice previews request Android audio focus, so starting another player pauses FolioTone and starting FolioTone asks the other player to yield. Focus interruptions, including requests to lower the volume, pause speech instead of talking over other audio. Disconnecting Bluetooth audio or unplugging headphones pauses narration and previews before they continue on the phone speaker. Playback stays paused until you press Play again, including after reconnection; it resumes at the saved page. Pausing, finishing, or leaving a voice preview releases audio focus.

The app targets Android 8.0 and later. Folder selection follows Android's Storage Access Framework restrictions; some device roots and the Downloads directory cannot be selected as a tree on recent Android versions. Individual EPUBs can still be imported from Downloads.
